# StayQatar — Hotel & Villa Booking Website

A portfolio-ready full-stack accommodation discovery website inspired by the visual style of the supplied reference video.

## Tech stack
- Frontend: HTML5, CSS3, JavaScript (ES6+)
- Backend: Python 3 + Flask
- Database: SQLite
- API: REST-style JSON endpoints
- Responsive design: desktop, tablet and mobile
- External image CDN: Unsplash URLs

## Features
- Full-screen hero image carousel
- Qatar-focused accommodation cards
- Search by destination/name/type
- Hotel/Villa/Apartment filtering
- Favorites saved in browser localStorage
- Hotel detail modal
- Working booking form
- Server-side booking validation
- SQLite booking storage
- Responsive mobile layout
- Clean portfolio/GitHub structure

## Run on Windows

1. Install Python 3.10+.
2. Open Command Prompt inside this project folder.
3. Create a virtual environment:
   `python -m venv venv`
4. Activate it:
   `venv\Scripts\activate`
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start:
   `python app.py`
7. Open:
   `http://127.0.0.1:5000`

The database file `bookings.db` is created automatically on first run.
